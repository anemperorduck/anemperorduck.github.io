3. model_dump(exclude_none=True) 详解

model_dump() 来自 Pydantic——OpenAI SDK 的返回对象（如 response.choices[0].message）底层都是 Pydantic 的 BaseModel 子类。

model_dump()

把 Pydantic 模型对象递归转换成普通 Python 字典。直接打印对象只能看到 repr，无法 JSON 序列化、不方便按 key 遍历；model_dump() 是官方提供的「对象 → dict」出口：

嵌套结构（如 tool_calls）会被一层层全部转成 dict，不只转最外层。

exclude_none=True

转换时把值为 None 的字段直接丢掉。

OpenAI 返回的 message 对象里很多未用字段会被 Pydantic 填成 None（而不是省略），不排除会得到一堆噪音：

尤其把这条 message 塞回 messages 做多轮对话时——有些 API 对 null 字段会报错或行为异常，去掉 None 字段更安全。

常用兄弟参数

参数 作用
exclude_none=True 排除值为 None 的字段
exclude_unset=True 排除「没被显式赋值」的字段
exclude={"audio", "annotations"} 按名字精确排除指定字段
include={"content", "role"} 只保留指定字段

model_dump(exclude_none=True) 是最常见选择：保留所有有意义的数据，只剔除空值。
